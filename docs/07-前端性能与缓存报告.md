# 前端性能与缓存报告

> P5 产物。E2E 证据见 `artifacts/playwright/map.png` 与 `artifacts/frontend/perf.json`。

## MVVM 结构

前端目录按冻结规格拆分：

```text
frontend/src/features/{map,forms,batches,stats,docs}/{model,view-model,view}
```

- `model`：API 类型、请求函数、ETag 处理。
- `view-model`：筛选条件、分页/操作状态、TanStack Query key。
- `view`：只渲染界面和触发 ViewModel 动作。

## 缓存与网络请求

P5 已实现三层缓存中的两端，并接入后端 Redis：

| 层 | 实现 |
|---|---|
| HTTP ETag/304 | `/api/v1/clusters` 返回弱 ETag；前端 `apiFetchWithEtag` 复用 304 前一次数据。 |
| Redis | 后端 `clusters:v1:{tenant}:{bbox_hash}:{zoom}:{filter_hash}`，TTL 60 秒。 |
| TanStack Query | 表单 30 秒、统计 10 秒、聚合 15 秒；WS/轮询事件触发 invalidate。 |

WebSocket 地址：`/api/v1/ws?token=...`。断开后前端自动降级为 `/api/v1/events?since=seq` 轮询。
