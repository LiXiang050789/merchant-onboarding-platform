### 3.2 API 契约

【必须冻结】端点清单：

| 方法 | 路径 | 请求/响应要点 |
|---|---|---|
| `POST` | `/api/v1/auth/login` | email/password → access_token、refresh_token、expires_in |
| `POST` | `/api/v1/auth/refresh` | refresh_token → 新 access_token |
| `GET` | `/api/v1/forms` | filters + `page,size`；返回 `items,total,page,size` |
| `POST` | `/api/v1/forms` | `Idempotency-Key` header + form body；重复键返回原 form |
| `GET` | `/api/v1/forms/{id}` | tenant scope |
| `PATCH` | `/api/v1/forms/{id}/status` | `target_status`；非法流转 409 |
| `GET` | `/api/v1/clusters` | `bbox,zoom,form_type,status,city,from,to`；返回 GeoJSON FeatureCollection |
| `POST` | `/api/v1/batches/build` | filters + capacity + radius_m；返回 batch summary |
| `GET` | `/api/v1/batches` | 分页 |
| `POST` | `/api/v1/batches/{id}/run` | 幂等触发 |
| `GET` | `/api/v1/stats/success-rate` | window + filters；返回三口径 |
| `POST/GET/PATCH/DELETE` | `/api/v1/docs` | CRUD；PATCH 要 `If-Match` |
| `POST` | `/api/v1/docs/{id}/rollback` | `version_no` → 新版本 |
| `GET` | `/api/v1/ws` | `Authorization` 或 `token`；事件增量 |

【必须冻结】错误码：400 校验失败；401 未登录；403 越权；404 不存在或跨租户隐藏；409 幂等冲突/非法状态/版本冲突；422 业务字段错误；500 未预期错误。

【必须冻结】JWT：RS256 或 HS256 二选一。推荐一周内用 HS256，`.env` 保存密钥，access 30min，refresh 7d；WebSocket 首次连接用 `?token=`，服务端校验后绑定 tenant。

### 3.3 状态机

【必须冻结】

| from | to | 触发者 | 条件 | 拒绝语义 |
|---|---|---|---|---|
| draft | submitted | merchant | 必填字段完整 | 422 |
| submitted | validating | system | 入队校验 | 409 非 submitted |
| validating | validated | system | schema/坐标/权限通过 | 409 |
| validating | rejected | system/operator | 校验失败 | 记录原因，终态 |
| validated | batched | system | 被批次选中 | 409 |
| batched | processing | worker | 批处理启动 | 409 |
| processing | published | worker | 管线完成 | 409 |
| processing | failed | worker | 可重试异常 | 写 DLQ |
| failed | processing | worker/operator | retry_count < 3 | 超限保持 failed |

### 3.4 聚合算法参数

【必须冻结】

| 参数 | 默认值 |
|---|---|
| zoom→grid size | z<=8: 0.2°；9-10: 0.1°；11-12: 0.05°；13-14: 0.02°；>=15: 0.01° |
| bbox | `[west,south,east,north]`，必须校验 west<east、south<north |
| 批次容量 | 50 条/批 |
| 最大合批半径 | 3000m，同城市内生效 |
| 距离公式 | 候选排序用等距圆柱近似：`x=(lng2-lng1)*cos(avgLat)*111320`，`y=(lat2-lat1)*110540`；最终用 Haversine 校验 |
| 跨城市边界 | 先按 `city_code` 分区，不跨城市合批 |

### 3.5 成功率 SQL 语义

【必须冻结】

| 口径 | 分母 | 分子 | 去重 |
|---|---|---|---|
| 提交成功率 | `submit_attempt` | `submit_api_success` | 按 `tenant_id,idempotency_key` 每窗口取首次 attempt |
| 落库成功率 | `submit_attempt` | `db_insert_success` | 同上 |
| 端到端成功率 | 去重后的 `submit_attempt` | 最终状态为 `business_published` | 以 `idempotency_key` 归集最终态 |

时间窗：按 `received_at` 入窗；乱序事件允许 10 分钟迟到，统计接口默认近 24h，支持 `from/to`。

### 3.6 合成数据规格

【必须冻结】随机种子 `20260918`；100000 条；城市权重：上海 30%、北京 25%、深圳 20%、杭州 15%、成都 10%；每城 5 个商圈中心，高斯扰动 sigma 0.02°；异常注入：坐标越界 0.5%、缺必填 1%、重复幂等键 1%、非法状态样本 0.2%。

### 3.7 缓存与失效

【必须冻结】

| 事件 | 后端动作 | 前端动作 |
|---|---|---|
| form_created/form_updated/status_changed | 删除 `clusters:*` 与相关 stats key；发布 WS | invalidate `forms`,`clusters`,`stats` |
| batch_created/batch_updated | 删除 batch list key；发布 WS | invalidate `batches`,`clusters` |
| doc_updated/doc_deleted | 删除 docs key | invalidate `docs` |

ETag：基于 `resource_version + filter_hash + max(updated_at)` 生成弱 ETag。TanStack Query：列表 `staleTime=30s,gcTime=5min`；统计 `staleTime=10s`；聚合 `staleTime=15s`。

## T4. 环境与技术声明核查

结论：Docker、Node、npm、Spark 主体可用；Mongo 本机不可用且本地无 Mongo 镜像；网络在沙箱内不可达、非沙箱可达。Mongo 中文全文检索不应作为主检索方案。

| 项 | 结论 | 命令与输出摘录 | 改法 |
|---|---|---|---|
| Docker daemon | 属实，非沙箱可用；沙箱内无权限 | `docker info` 沙箱：`permission denied ... docker.sock`；非沙箱：`Server Version: 29.7.2`, `Containers: 2`, `Images: 5` | README 写明需 Docker Desktop 运行；Codex 沙箱内需授权。 |
| Compose | 属实 | `docker compose version` → `Docker Compose version v5.5.1`; `docker-compose version` 同样可用 | 主命令用 `docker compose`。 |
| 本地镜像 | 有 MySQL，无 Mongo | `docker images` → `mysql:8.0` 存在；未见 `mongo` | P0 若需 Mongo 必须 pull，需预留网络/镜像源时间。 |
| Node/npm | 属实 | `node -v` → `v24.14.0`; `npm -v` → `11.9.0` | Next 当前 engines 可接受 Node 24。 |
| Next.js 15 要求 | 有条件成立 | `npm view next version engines` → 当前 `16.3.5`, `node >=20.9.0` | 若坚持 Next 15，`package.json` 固定 `next@15`，不要默认装 latest。 |
| PySpark 3.5.0 + Python 3.13.11 | 本机最小作业可跑，但版本支持有隐患 | 非沙箱命令输出最终 `5`；沙箱失败是 `Socket creation failed` | 建议 P6 前建 Python 3.11 环境作为 Spark 专用；否则保留“本机已实测可跑，但非官方稳态组合”的风险说明。 |
| Mongo 中文全文检索 | 未实测；官方行为显示不适合中文长句强检索 | `mongod --version` → `command not found`；官方文档：text index 按 Unicode 空白/标点等分隔符 tokenize | R4 检索改为 jieba 预分词 `tokens[]` + multikey 索引，或自建倒排集合。 |
| MapLibre GL 无 Key | 属实，但底图瓦片仍需来源 | `npm view maplibre-gl version license` → `6.10.0`, `BSD-3-Clause` | 代码可无 Key；演示需选择可公开访问 tile source，或本地 GeoJSON 空白底图降级。 |
| TanStack Query SWR | 属实 | `npm view @tanstack/react-query version` → `5.103.1`；官方文档：`staleTime` 控制变 stale，`gcTime` 默认 5 分钟 | v3 写清 staleTime/gcTime/invalidate，不用“SWR”泛称代替契约。 |
| FastAPI WS + async SQLAlchemy | 有条件成立 | 未启动项目；工程事实：WS 常驻连接不能长期占用 DB session | WS handler 只鉴权一次并发布/订阅消息；DB 操作用短 session；MySQL async 驱动推荐 `asyncmy`。 |
| 网络 | 非沙箱可达，沙箱不可达 | 沙箱 `curl` → `Couldn't connect to server`；非沙箱 PyPI/GitHub/npm 均 200；Docker registry `/v2/` 返回 401 是正常鉴权挑战 | 依赖安装、镜像拉取需非沙箱或配置镜像；报告中不要承诺 GitHub 推送稳定。 |

参考：MongoDB text index tokenization 官方文档、TanStack Query v5 `staleTime/gcTime` 文档、MapLibre GL JS package/license。

## T6. 面试官视角：追问防线

结论：高级设计可以保留，但 P7 问答手册必须补“标准答法 + 证据文件”。当前最容易被问穿的是 Mongo 中文检索、Spark 必要性、缓存一致性、地理距离误差、WS 鉴权。

| 高级设计 | 追问 | 现有交付能否答上 | 必补材料 |
|---|---|---|---|
| 网格聚合 | zoom 为什么这样映射？边界点怎么处理？ | 不能 | P7 写参数表；P2 benchmark 证明 feature 数和耗时。 |
| 贪心容量批次 | 为什么不是最优聚类？会不会跨城市？ | 部分能 | 说明容量约束近似 NP-hard，工程贪心可审计；跨城市禁止。 |
| 三口径成功率 | 重试成功算不算成功？乱序怎么办？ | 部分能 | P3 SQL 和事件归集测试。 |
| 乐观锁与回滚 | 回滚会不会覆盖历史？并发写谁赢？ | 能 | docs 设计 + 并发冲突测试。 |
| ETag/Redis/SWR | 什么时候失效？304 和 Redis 谁先命中？ | 不能 | 缓存失效矩阵。 |
| DLQ/checkpoint | 重跑会不会重复发布？ | 部分能 | 批处理幂等键和重跑测试。 |
| Spark 同构验证 | 10w 为什么用 Spark？ | 能但要谨慎 | 标准答法：不用 Spark 做主路径，只展示规模化路径。 |
| RAG 检索质量 | 中文检索怎么保证？ | 不能 | 改为 jieba tokens/倒排，RAG 降级可选。 |
| RBAC 越权 | ORM 层漏 tenant 怎么办？ | 部分能 | repository 层统一 scope + 越权测试。 |
| WS vs 轮询 | 为什么不用轮询？断线怎么办？ | 部分能 | WS 仅增量；轮询为降级端点。 |
| MVVM | 代码里哪里体现 MVVM？ | 不能 | 前端目录和职责说明。 |

Top 5 最可能被问穿及一句话标准答法：

| 风险 | 标准答法 |
|---|---|
| Mongo 中文 text index | “Mongo text 不适合中文长句强分词，所以主线用 jieba 预分词 tokens + multikey 索引，RAG 只是可选问答层。” |
| Spark 必要性 | “10w 单机 Python 更合适，Spark 不做主路径，只用同构测试证明将来可迁移到分布式。” |
| 缓存一致性 | “写操作发布资源版本变更，后端删 Redis，前端收到 WS 后 invalidate query；ETag 用版本号和 max(updated_at) 生成。” |
| 地理距离准确性 | “网格只做候选缩小，最终合批用 Haversine 校验，跨城市先分区，避免经纬度欧氏距离误用。” |
| 权限隔离 | “所有业务表带 tenant_id，repository 层统一注入 tenant scope，越权返回 404/403，并有集成测试证明。” |
