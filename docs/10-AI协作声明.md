# AI 协作声明

本项目允许使用 AI 辅助工程执行，但交付目标不是“让 AI 代写后无法解释”，而是把方案拆成可验证、可复现、可答辩的工程证据。

## 使用方式

- AI 辅助做方案审查、任务拆解、代码实现、测试补齐和文档整理。
- 所有关键命令均真实运行，并把结果落盘到 `artifacts/`。
- 冻结规格、审查记录和执行账本都保留在 `docs/`，便于追溯。

## 候选人需要掌握

- 每个 API 的权限边界和错误语义。
- 地理聚合的 grid/bbox/zoom 关系。
- 成功率三口径的分母、分子和幂等去重。
- 批处理的 checkpoint、DLQ、幂等重跑。
- Mongo 文档版本、软删、乐观锁和回滚。
- Spark/RAG/预测为何是加分项而非主线。

## 不声明为候选人手写的部分

不应声称所有代码逐字符手写。更准确的说法是：

> 我使用 AI 作为结对工程助手，但我能解释核心设计、权衡、测试证据和已知限制；提交物以可运行代码、测试和文档为准。

## 安全边界

- `.env` 不入库。
- DeepSeek/GitHub 等 API key 不写入文档和代码。
- PAT 曾在对话中出现，但已由用户在 GitHub revoke。
