# 面试问答手册

## 1. 为什么不用 C++？

答：本题瓶颈不是纯 CPU 算法，而是查询过滤、payload、缓存和渲染。10w 规模下 Python/Numpy/SQL 已经能跑出可解释的结果；引入 C++ 会增加构建、调试和答辩复杂度。证据是 `scripts/benchmark_aggregation.py` 和 `artifacts/bench/aggregation.json`。

## 2. 为什么不用 PostGIS？

答：PostGIS 很适合生产空间查询，但本作业一周时间内要同时覆盖权限、表单、统计、批处理、前端和文档域。当前 bbox + 网格聚合满足题目规模，且部署更轻。生产路径可以把 `forms.lng/lat` 迁移为 geography 并建 GIST 索引。

## 3. H3 为什么没进代码？

答：H3 是好方案，但会增加新依赖和 hex cell 口径解释成本。本项目用 zoom→grid size 的规则，面试时能直接说明 bbox、cell、count、centroid 的关系。

## 4. cKDTree 的作用是什么？

答：作为算法对照和候选检索路径，不是默认渲染路径。城市级视野候选率高时，网格+payload 缩减收益更稳定；KDTree 在小范围/高 zoom 场景可能更有价值。

## 5. 怎么证明 10w 点没有下发给前端？

答：前端请求 `/api/v1/clusters`，返回 GeoJSON features 是聚合簇数量，不是原始表单数量。Playwright 断言 marker 数等于 features；性能证据在 `artifacts/frontend/perf.json`。

## 6. 成功率为什么有三种口径？

答：客户端提交成功、服务端落库成功、业务最终发布是不同问题。网络重试可能导致客户端失败但服务端成功；落库成功也不代表最终业务发布。代码在 `backend/app/stats.py`。

## 7. 幂等键怎么生成？

答：Web 端应在提交前生成 UUID 并持久到请求上下文；本 demo 用 `Idempotency-Key` header。服务端以 `(tenant_id,idempotency_key)` 唯一约束兜底。

## 8. 为什么跨租户资源返回 404 而不是 403？

答：避免泄露资源存在性。用户无权访问时，不告诉他“这个 id 在别的租户存在”。

## 9. operator 和 admin 有什么区别？

答：admin 可跨租户演示后台操作；operator 受 `region_code` 限制，只能看和处理自己区域允许的流转。测试覆盖 operator 上海区域过滤。

## 10. 批处理为什么按 `(tenant_id, city_code)` 分组？

答：城市约束保证地理聚合正确，tenant 约束保证数据隔离。P4 抽查发现只按 city 会跨租户合批，已修复并加回归测试。

## 11. 批次失败怎么恢复？

答：管线 fail-fast，写 DLQ 和 checkpoint。修复后重跑同一批次，已 published 的跳过，未完成的继续推进。

## 12. 文档删除为什么是软删？

答：知识文档有审计和回滚需求，硬删会丢失历史语境。默认查询只看 active，历史版本保留。

## 13. 文档并发怎么处理？

答：PATCH 必须带 `If-Match: current_version`。版本不一致返回 409，调用方重新拉取后再编辑。

## 14. 回滚会覆盖历史吗？

答：不会。回滚读取旧版本内容，创建一个新的当前版本，并记录 `rollback_from_version`。

## 15. Mongo text index 为什么不用？

答：中文长句分词不可控。本项目用 jieba 预分词写入 `tokens[]`，Mongo multikey 索引用于检索。

## 16. RAG 做到什么程度？

答：脚本可基于 Mongo tokens 检索并输出引用。当前环境没有 `DEEPSEEK_API_KEY`，所以证据是 retrieval-only；如果提供 key，脚本会调用 DeepSeek。

## 17. Spark 为什么比 Python 慢？

答：100k 本地 CSV 下 Spark 的 JVM 启动和 shuffle 成本大于计算收益。这里 Spark 是规模化同构路径，证据是 Python 与 Spark 结果完全一致。

## 18. 报表预测是不是过度？

答：它是轻量加分项，用 7 日均值和线性趋势做可解释预测，回应 JD 的“一点点机器学习”。不作为核心业务决策。

## 19. WebSocket 断了怎么办？

答：前端有 `/api/v1/events?since=` 轮询降级。E2E 覆盖了轮询事件契约，运行环境安装 `websockets` 后 WS 可握手。

## 20. 为什么 README 透明声明 AI 协作？

答：这个作业要面试当面讲清楚。透明说明 AI 辅助和候选人理解边界，比隐藏更稳。
